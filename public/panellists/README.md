Put panelist images in this folder.

Filename format:

- `first-last.png`
- `first-last.jpg`
- `first-last.jpeg`
- `first-last.webp`

Examples:

- `abhinandan-sekhri.jpg`
- `manisha-pande.png`
- `tm-krishna.jpg`

The app checks this folder first and falls back to the existing remote image lookup if no local image is found.
